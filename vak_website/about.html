दृष्टि (Vision)

Sanskrit was not chosen for nostalgia. Panini's Ashtadhyayi (~500 BCE) is a formal generative grammar structurally isomorphic to a programming language's formal grammar. This project plants that seed: Sanskrit as a real computing substrate, not a curiosity.

प्रेरणा (Inspiration)

"वाक् वै ब्रह्म" — Speech is indeed the universal principle.

NASA researcher Rick Briggs noted in 1985 that Sanskrit grammar is ideal for AI knowledge representation. वाक् takes that insight into a fully working programming language.
